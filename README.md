# angular_text_analyzer
Третяк Мирослав і Денис Семкович 

Що це таке?
Текстовий аналізатор - це веб-додаток, куди ти вставляєш або пишеш текст, а він автоматично показує тобі різну статистику про цей текст

Навіщо це потрібно?
Письменникам для відстеження обсягу тексту, студентам для перевірки есе на кількість слів, маркетологам для аналізу постів, блогерам для оптимізації статей
